# Agncy

> The in-house personal content agency workspace for one.

A local-first, offline-capable studio application combining an AI scriptwriter with edit-learning loops, an autonomous idea generator with Google Search grounding, local high-speed speech-to-text captions via Apple Silicon, and closed-loop Meta Business Suite analytics.
